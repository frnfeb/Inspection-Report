Petunjuk Pengisian

Diambil dari sheet TUTORIAL pada template resmi — dokumen acuan operator sebelum mengisi Inspection Report.

A

Petunjuk Pengisian "Summary Inspection Report"

  1. Area yang di-highlight kuning boleh diisi dengan tulisan free-text sesuai contoh.
  2. Bagian yang biru harus diisi mengikuti drop down list.
  3. Jika ada item yang tidak tercantum di list, mohon diinformasikan ke PIC Report per Plant (akan didiskusikan untuk penambahan list).
  4. Jika perlu mencantumkan detail informasi lainnya, dapat diisi di bagian "Notes:".
  5. Bagian PHENOMENA diisi dengan "Type of Equipment / Part of Equipment + Phenomena".
  6. Bagian CONTENT diisi dengan "Part of Equipment / Detail of Part + Kind of Inspection or Maintenance Activity".
  7. Bagian CAUSE diisi sesuai list "Direct Cause" dan "Root Cause".
    • Direct Cause = kenapa "PHENOMENA" terjadi? (contoh: kenapa High Vibration & Bearing Abnormal Sound → karena Bearing Damage (Oil Contamination), Rubber Coupling Damage).
    • Root Cause = kenapa "Direct Cause" bisa terjadi? (contoh: kenapa Bearing Damage (Oil Contamination) → karena No Water Splasher Installed, Coupling Misalignment).
  8. Bagian Next Action diisi dengan follow up action yang perlu dilakukan di next overhaul (format harus sesuai panduan).
  9. Bagian Counter Measure diisi dengan aksi yang telah dilakukan untuk mencegah "Root Cause" terjadi lagi (format harus sesuai panduan).
  10. Bagian Recommendation diisi dengan ide improvement yang dapat dilakukan untuk meningkatkan kualitas mesin.
  11. Bagian Result of Test Run diisi sesuai hasil test-run (lihat Lampiran).
    • Khusus bagian "Vibration Result", mengikuti standard common centrifugal pump. Untuk special equipment, silakan konfirmasi ke tim monitoring.
  12. Bagian Remarks diisi data full close (penting untuk analisa performa).
    • Jika ada hal lain yang perlu diinformasikan, tulis di "Other Remarks".
  13. Bagian Replacement Parts diisi dengan part-part yang diganti, tuliskan detail spesifikasi dan/atau materialnya (semakin detail semakin baik).
  14. Bagian Notes dapat digunakan untuk mencantumkan informasi lain.
  15. Jangan lupa menuliskan nama penulis di bagian "Written" untuk approval report.
  16. Report yang memerlukan Detail Inspection Report untuk Centrifugal Pump dapat diisi di sheet CPL Pump.
  17. Report yang memerlukan Check Point List (CPL) equipment lain, dokumennya dapat diminta ke Staff terkait.
  18. Lampirkan dokumentasi inspeksi di sheet Inspection Photograph.
B

Petunjuk Penyimpanan & Alur Approval / Revision

  1. Buka file "Inspection Report Online Template (Read Only)" di Box\TEMPORARY\000 Online Inspection Report (Trial).
  2. Klik "File" kemudian "Save As", simpan file di folder masing-masing.
  3. Isi Summary Inspection Report sesuai petunjuk di bagian A.
  4. Jika sudah lengkap, klik "Ctrl + P" kemudian atur setting berikut:
    • Printer = "Microsoft Print to PDF"
    • Setting = "Print Entire Workbook"
    • Pages = 2-4 (default jika report lengkap); sesuaikan dengan kebutuhan
    • Lalu klik "PRINT"
  5. Berikan nama file sesuai format: TAG.NO_TANGGAL-ACTION_PROBLEM_NAMA
    Contoh: PU-1502-B_20260220_ABNORMAL SOUND_RAMA
  6. Simpan file di lokasi folder plant masing-masing.
    Contoh (CA-Plant): Box\TEMPORARY\000 Online Inspection Report (Trial)\CA Plant\1. Report Teknisi (initial and Revised)
  7. Report dari Teknisi akan di-check oleh Staff PIC per plant.
    • Jika Approved akan disimpan di folder "2. Approved by Staff"
    • Jika perlu revisi akan disimpan di folder "4. Need to be Revised"
  8. Staff bertanggung jawab melakukan follow-up ke Section Chief terkait report yang sudah "approved by staff".
  9. Section Chief akan melakukan review final untuk report tersebut.
    • Jika Approved akan disimpan di folder "3. Approved by SC"
    • Jika perlu revisi akan disimpan di folder "4. Need to be Revised"
  10. Report yang sudah ada di folder "Approved by SC" akan dipindahkan oleh Admin ke ASC EDB.

Langkah 1, 2, 4, dan 6 di atas mengacu ke alur Excel manual (Save As / Ctrl+P / simpan ke folder Box). Setelah Inspection Report by FRNFEB aktif, langkah-langkah tersebut digantikan oleh tombol Generate Excel & PDF pada form — sisanya (alur approval Staff → Section Chief → EDB) tetap berlaku.

Lampiran
